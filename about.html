Purpose

TaskFlow is a lightweight, containerized task-management application deployed via a seamless GitHub Actions CI/CD pipeline.

Usage Guide

  • Dashboard: Get a bird's-eye view of your productivity metrics.
  • Add Task: Input new objectives and assign priorities and deadlines.
  • Task List: Sort and filter your current backlog of assignments.
  • Task Detail: Dive into specifics and manage the lifecycle of a single objective.
